Telnet-клиент для социальной сети [LainLife](https://lainlife.org). Выше показаны скриншоты работы данного Telnet-клиента из-подпод терминала **Telix** 1989 года, запущенного в операционной системе MS-DOS.

## Функционал
На данный момент поддерживаются:
- Логин в аккаунт соцсети
- Чтение ленты (как своей собственной, так и глобальной)
- Просмотр профилей, информации о пользователях, а также их стен
- Система друзей - просмотр текущего списка друзей, отправка и принятие заявок
- Система ЛС - просмотр текущего списка сообщений, возможность отправки в существующие чаты, возможность писать другим пользователям
- Создание постов на своей и чужой стене

Кроме того, всё это поддерживает работу с кириллицей и форматирование постов по стандарту LainLife.

## Установка
Скачайте репозиторий и запустите сервер командой:
```
python3 main.py
```

Поддерживаются аргументы:
```
  --host HOST          - хост, на котором будет работать сервер
  --port PORT          - порт, на котором будет работать сервер
  --instance INSTANCE  - выбор инстанса по умолчанию
  --encoding ENCODING  - для пропуска проверки кодировки клиента, то есть
                         весь сервер всегда будет работать в одной кодировке: utf-8 / cp866 / cp1251.
  --stdio              - запуск telnet-клиента без сервера
```
